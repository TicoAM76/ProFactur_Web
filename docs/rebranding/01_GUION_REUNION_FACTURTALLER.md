
# Guion de presentación para la reunión

## Mensaje principal

FacturTaller es una solución de gestión integral para talleres, desarrollada sobre una plataforma modular reutilizable de RN Soluciones Digitales.

No se presenta como otro programa genérico de facturación.

## Problema que resuelve

Muchos talleres trabajan con una combinación fragmentada de:

- papel;
- hojas de cálculo;
- WhatsApp;
- programas antiguos;
- presupuestos separados;
- poca trazabilidad del vehículo;
- facturación manual.

FacturTaller concentra el recorrido:

cliente
-> vehículo
-> presupuesto
-> orden de reparación
-> trabajo y piezas
-> factura
-> PDF y QR
-> Veri*Factu
-> verificación

## Qué puede demostrarse hoy

1. Acceso protegido al panel.
2. Empresa de demostración.
3. Cliente y vehículo.
4. Creación guiada de factura DEMO.
5. Cálculo automático de IVA.
6. Número y PDF.
7. XML y hash fiscal.
8. QR público por HTTPS.
9. Página visual de verificación.
10. Aviso transparente de que no se ha enviado a AEAT.

## Qué está preparado técnicamente

- API NestJS;
- PostgreSQL;
- Redis;
- Prisma;
- frontend Next.js;
- Docker;
- PDF basado en snapshots;
- XML estructurado;
- validación contra XSD oficial;
- hash fiscal;
- preparación de envíos;
- arquitectura de RN Bridge.

## Qué todavía no debe afirmarse

No afirmar que:

- el producto está homologado;
- AEAT ha aceptado documentos reales;
- existe envío de producción;
- RN Bridge está terminado;
- el sistema está listo para venta masiva;
- la sociedad o la marca están registradas.

## Diferenciación

La ventaja no es solamente Veri*Factu.

La propuesta diferencial es:

- especialización en talleres;
- seguimiento del vehículo;
- órdenes de reparación;
- presupuestos y aceptación;
- piezas y mano de obra;
- estados del trabajo;
- historial por matrícula y bastidor;
- comunicación con el cliente;
- factura y cumplimiento en el mismo flujo.

## Decisiones que deben salir de la reunión

1. Confirmar la sociedad entre Rafael y Nestor.
2. Acordar participaciones, aportaciones y responsabilidades.
3. Aprobar provisionalmente RN Soluciones Digitales.
4. Aprobar FacturTaller como primer producto.
5. Validar prioridades reales del taller.
6. Elegir el siguiente módulo.
7. Definir alcance del piloto.
8. Establecer titularidad del código, dominios y marca.

## Frase de cierre

FacturTaller no pretende ser únicamente un programa para emitir facturas. Es el primer módulo sectorial de una plataforma empresarial de RN Soluciones Digitales, diseñada para acompañar el trabajo del taller desde la entrada del vehículo hasta su facturación y entrega.
