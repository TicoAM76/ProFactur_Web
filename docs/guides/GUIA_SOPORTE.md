# Guía de soporte — Borrador

## Información a solicitar

- Empresa.
- Usuario.
- Fecha y hora.
- Acción.
- Número de factura.
- Estado mostrado.
- Captura.
- Versión de Bridge futura.
- Estado del agente.

## Información que nunca debe solicitarse

- PFX/P12.
- Contraseña del certificado.
- Clave privada.
- Token completo.
- `.env`.

## Niveles

### Nivel 1

- Usuario.
- Navegador.
- Datos.
- PDF.
- Estado visible.

### Nivel 2

- API.
- Base de datos.
- Migraciones.
- Bridge.
- Colas.

### Nivel 3

- Seguridad.
- AEAT.
- Certificados.
- Corrupción de cadena.
- Recuperación.
