# Guía de instalación — Borrador

## Alcance actual

Esta guía es un borrador técnico. No representa todavía un instalador comercial final.

## Componentes

- RN Business Core Cloud.
- PostgreSQL.
- Redis.
- API.
- Frontend.
- RN Bridge futuro.

## Instalación Cloud

1. Preparar servidor.
2. Instalar Docker.
3. Clonar repositorio.
4. Crear `.env`.
5. Levantar servicios.
6. Aplicar migraciones.
7. Configurar proxy.
8. Verificar salud.

## Instalación Bridge

**PENDIENTE**

- Windows 11.
- TPM 2.0.
- Código de emparejamiento.
- Servicio Windows.
- Certificado local.
